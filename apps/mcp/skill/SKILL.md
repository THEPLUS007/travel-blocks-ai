# Travel Blocks MCP

Use `analyze_travel_source` for credential-free JSON-RPC testing. This MCP app is intentionally separate from the web API and returns a deterministic fallback draft. It does not claim to call Gemini, fetch URL bodies, search verified places, or persist trips.
