# Travel Blocks AI Repository Rules

This repository is the active codebase for the production-deployable Travel Blocks AI service. It is not the archived AX competition submission.

- Read the current implementation and existing abstractions before changing code.
- Do not treat Mock-only behavior as production success.
- Do not leave temporary workarounds as production solutions.
- Never commit `.env` files, API keys, database credentials, tokens, or other secrets.
- Avoid unnecessary large rewrites and preserve existing behavior unless the task requires a change.
- Run the relevant lint, typecheck, tests, and build after each meaningful change.
- Keep commits focused and meaningful. Do not force-push or rewrite shared history.
- Document required external services and environment variables without recording secret values.

Replace or extend this file when the project master prompt is provided.
